# Refatoracao — projeto inicial (Java SE 15)

Projeto Eclipse reproduzindo a implementação inicial do enunciado da AT de Análise de Sistemas II, **sem aplicar as cinco refatorações**.

## Importação no Eclipse

1. Descompacte o arquivo ZIP.
2. File > Import > General > Existing Projects into Workspace.
3. Selecione a pasta `Refatoracao` e conclua.
4. Configure um JDK 15 no Eclipse (Window > Preferences > Java > Installed JREs), caso necessário.
5. Clique com o botão direito em `Main.java` > Run As > Java Application.

## Observações

- Classes no pacote padrão, conforme o enunciado.
- Data fixa `10/09/2025`, conforme o exemplo.
- Os problemas de qualidade do código foram mantidos intencionalmente para a atividade de refatoração.
